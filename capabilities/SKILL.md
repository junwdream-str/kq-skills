# 能力清单

用户问「你能做什么」时，不要凭印象回答。用脚本扫描本机真实安装的 skill，只列与钉钉、日常业务相关的项，按固定格式输出。

## 执行

```bash
python ~/.workbuddy/skills/capabilities/scripts/list_skills.py --format brief
```

默认只输出业务相关技能（脚本内 BUSINESS 白名单：binkang-daily-report、dingtalk-robot-publish、dws）。只有用户明确要求看全量时才加 `--scope all`。

## 输出格式（严格）

只输出编号条目，一条一行，格式固定为「序号. 技能名 — 中文短注」。

```
1. binkang-daily-report — 滨康大区日报周报汇总出图
2. dingtalk-robot-publish — 按群名向钉钉群发机器人消息
3. dws — 钉钉全产品操作入口
```

硬性要求：

- 序号从 1 连续递增，覆盖脚本返回的全部条目，不筛选、不省略、不增补。
- 注释必须是中文，控制在 6 到 16 个字。脚本给的是原始 description，遇到英文、带括号的技术说明或过长内容，一律自己概括成简短中文短语，禁止出现英文词句。
- 技能名本身是英文标识符，保持原样不动。
- 不加任何标题、分组名、分类小标题。
- 不加前言、结尾、总数统计、"以上"之类的收束语。
- 不加追问引导，不推荐安装其他技能。
- 不输出技能路径。

## 例外

- 用户明确要求「全部技能 / 完整清单」时，改用 `--scope all`，保持同样的编号格式，此时条目会明显变多。
- 用户明确要求按类别看时，才允许加分组标题。
- 脚本扫不到结果时，直接回一句当前未安装相关技能。
- 用户问到某个具体需求而清单里没有对应技能时，先按上面的格式列完清单，再用一句话说明该项暂不支持。
- 回答语言跟随用户提问语言。
