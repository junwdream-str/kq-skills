# 滨康大区经理日报汇总

把钉钉日志「滨康新日报表」的填报数据，按约定口径换算成日增量与周累计，输出一份 ECharts 图表 HTML。

## 强制性规则

1. **数据源只能是钉钉日志接口，禁止用群消息文本。** 群内推送的日报文本是残缺的，只渲染前 8 个字段，「回访目标/回访完成/自媒体目标/自媒体完成/今日拜访零售店数量」5 项全部缺失（表现为两个无标签的孤立 0）。群消息只能用来核对"谁提交了、谁没提交"。
2. **不修改、不修正任何原始数值。** 发现异常只标注，不回填、不平滑、不剔除。
3. **图表样式必须严格遵守 `references/chart-style.md`。** 颜色、字体、图形选型、坐标轴处理、CDN 与降级都在该文件里，不得自行发挥。
4. 固定名单与固定字段以下文为准，不要向用户确认已约定事项。

## 固定名单（10 人，顺序固定）

杨成长、陈阳、李丛恩、叶占国、汪洋、杨万鹏、李双伟、纪昌波、李继锋、许森林

## 固定字段（11 项，顺序固定）

本周发货目标（万）、累计发货金额（万）、本周试验目标（个）、累计完成试验（个）、本周会议目标（个）、累计完成会议（个）、本周回访试验/用户目标（个）、累计完成回访（个）、本周自媒体目标（个）、累计完成自媒体（个）、今日拜访零售店数量（个）

索引约定：偶数位 0/2/4/6/8 为**目标**，奇数位 1/3/5/7/9 为**累计完成**，10 为**当日**口径的拜访零售店数量。

## 计算口径（8 条，已与用户确认，不要更改）

1. 未提交者全部计 0，并纳入分母。
2. 数据按真实值处理，不做修正。
3. 目标为 0 的项同样计入达成率计算，不剔除。
4. 只做统计，不做主观判断与建议。
5. 拜访零售店为 0 属正常，不标记。
6. 目标取**本周首次填报值**（该周第一次提交时填的目标；整周未提交则为 0）。
7. 日总结用**当日增量** = 当日累计 − 前一日累计；周一增量即周一累计值。周总结用**本周最后累计值**（该周最后一次提交时的累计）。
8. 名单固定，不做增减。

## 执行步骤

### 第一步：定位日志 ID

对每个日期单独执行，游标从 0 起，每页 20，翻到本页返回不足 20 条或无新增为止：

```bash
dws report inbox list --start "YYYY-MM-DDT00:00:00+08:00" --end "YYYY-MM-DDT23:59:59+08:00" --size 20 --cursor N --format json
```

返回项的键是中文，reportId 嵌在「钉钉链接」里，用 `id%3D([0-9a-f]{16,})` 提取。按「发送人」过滤固定 10 人。

注意：`inbox list` 返回的是全公司发给当前用户的日志，单日通常 50 条以上，必须翻页；单次调用约 3–5 秒，三天串行约需 1 分钟，请为整段命令设置较长超时。

### 第二步：读取明细

```bash
dws report entry get --report-id <id> --format json
```

从 `result.report_content` 取 `key → value` 映射。`result.creatorName` 是可靠的姓名来源，不要用列表里的「发送人」。

### 第三步：计算与出图

直接调用脚本，它会完成取数、计算、异常检测与 HTML 渲染：

```bash
python skills/binkang-daily-report/scripts/binkang_report.py --start 2026-09-07 --end 2026-09-09 --out 报告.html
```

脚本会打印取数结果与异常清单，供你在回复中复述。随后用 `present_files` 打开生成的 HTML。

只做表格时加 `--format table`，只输出 JSON 加 `--format json`。

> **dws 调用陷阱（已内置在脚本里）**：Windows 上 `dws` 是一个 435 字节的 sh 脚本，Python 的 `subprocess` 无法直接执行，会报 `WinError 2`。脚本 `scripts/binkang_report.py` 已自动还原为 `node <.../dingtalk-workspace-cli/bin/dws.js> <args>`，并自动探测 node 与 dws.js 路径。若环境变化导致找不到，可用环境变量 `DWS_NODE` 与 `DWS_JS` 显式指定。在 Bash 工具里直接敲 `dws ...` 不受影响。

## 异常判定（脚本自动标记，需你在回复中点名）

- **累计回退**：任一累计列的当日值小于前一日值。累计完成数不可能减少，属填报错误。
- **未提交**：该日无日志，计 0 并在图上标注。
- **整日零产出**：已提交，但当日六项增量全为 0。可能是漏填，提示核实。
- **切片未清零**：周一填报值与上周最后一天完全一致，说明周报周期未切换。

## 输出契约

- 单文件 HTML，内嵌 ECharts CDN，无外部依赖（除 CDN 本身）。
- 四张图：达成率柱状图、目标与完成双轴分组柱状图、当日增量折线图、各人目标与完成横向条形图（可切换指标）。
- 不再输出表格；需要表格时用 `--format table` 生成 Markdown 片段。
- 图表下方固定列出数据异常说明。
