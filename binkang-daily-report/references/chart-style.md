# 图表样式强制约定

本文件是「滨康大区经理日报」出图的唯一样式依据。生成任何图表前必须读取并遵守。

## 一、主题与配色

深色主题，与 IDE 深色模式保持一致。

| 变量 | 色值 | 用途 |
|---|---|---|
| `--bg` | `#0d1117` | 页面背景 |
| `--card` | `#161b22` | 卡片背景 |
| `--card2` | `#1c2230` | 卡片头部、图例区、提示框 |
| `--line` | `#2a3140` | 边框 |
| `--tx` | `#e6edf3` | 主文本 |
| `--tx2` | `#9aa7b8` | 次级文本、图例、坐标轴名 |
| `--tx3` | `#6e7d90` | 弱文本、分隔线标签、基准线 |
| `--ac` | `#4c8dff` | 主色（蓝色），用于"完成"与发货 |
| `--ok` | `#3fb950` | 达标绿 |
| `--warn` | `#d29922` | 接近预警黄 |
| `--bad` | `#f85149` | 未达标红 |
| `--pu` | `#a371f7` | 辅色（紫），计数类指标的"完成" |

系列补充色：`#ec6cb9`（自媒体）、`#39c5cf`（拜访零售店）。

**不使用**纯黑背景、不使用浅色主题、不引入渐变填充、不使用 3D 效果。

## 二、图形选型规则

| 数据形态 | 必须用 | 禁止用 |
|---|---|---|
| 达成率对比（百分比、需与基准比较） | 柱状图 + `markLine` 基准线 | 折线图（类别间无连续关系）、饼图（达成率之和无意义） |
| 目标与实际完成（成对、类别 ≤ 6） | 分组柱状图 | 堆叠柱状图（目标与完成非构成关系） |
| 多日增量走势（时间序列） | 折线图 | 柱状图（柱高弱化趋势，看不出斜率拐点） |
| 各人对比（人数 ≥ 8、中文标签长） | 横向条形图（`yAxis.type='category'`） | 纵向柱状图（标签倾斜、可读性差） |

## 三、坐标轴处理

1. **量纲不同必须分轴。** 发货单位为万元，其余为个数。同轴会把 81 的自媒体目标压成矮柱、让 30 的发货失真。做法：发货系列绑 `yAxisIndex:0`，计数类系列绑 `yAxisIndex:1`，右轴关闭 `splitLine`。
2. 双轴图必须在副标题写明单位归属，例如"发货单位为万元（左轴），其余为个数（右轴）"。
3. 隐藏 `axisLine` 与 `axisTick`，`splitLine` 用 `#1f2531`，坐标轴名用 11px `--tx3`。
4. 百分比轴 `max:100`，不要留多余空白。

## 四、通用元素

- **图例**：置顶右侧，`itemWidth:14, itemHeight:8`，字号 12，色 `--tx2`。系列过多时保持一行，不与网格重叠。
- **网格**：`left:60, right:60~70, top:50, bottom:34~44`。双轴时右侧留 64 以上。
- **提示框**：`trigger:'axis', axisPointer:{type:'shadow'}`，背景 `#1c2230`，边框 `--line`，字号 12。
- **数值标签**：仅达成率柱显示，位置 `top`，格式 `'{c}%'`；其余图不显示标签，靠提示框取数，避免视觉噪声。
- **柱宽**：分组柱 `26%`，单系列柱 `46%`，横向条形 `32%`。圆角 `[4,4,0,0]`（横向为 `[0,4,4,0]`）。
- **折线**：`symbol:'circle', symbolSize:7`，线宽 2，主系列（发货）线宽 3。不做平滑 `smooth:false`，避免伪造趋势。
- **基准线**：`markLine` 虚线 `type:'dashed', width:1.5`，色 `--tx3`，标签写明含义与数值。

## 五、达成率分档（唯一允许的语义着色）

| 条件 | 颜色 | 含义 |
|---|---|---|
| ≥ 时间进度 | `--ok` 绿 | 领先 |
| 时间进度 −8 以内 | `--warn` 黄 | 持平偏弱 |
| 低于上述 | `--bad` 红 | 滞后 |

时间进度 = 已过工作日天数 ÷ 7。

## 六、交付与降级

1. ECharts 用 CDN：`https://cdn.jsdelivr.net/npm/echarts@5.5.0/dist/echarts.min.js`。
2. 必须做加载失败兜底：检测 `typeof echarts === 'undefined'`，显示红色提示条，说明可能离线并建议改用表格版。
3. 监听 `resize`，四张图全部 `resize()`。
4. 单文件输出，样式与脚本内嵌，不产生附加资源文件。
5. 需要离线使用时，把 ECharts 库下载到同目录并改为相对路径引用。
